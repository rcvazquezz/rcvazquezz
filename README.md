### 👨‍💻 Sobre mí

Soy desarrollador Full Stack con experiencia en PHP (CodeIgniter), JavaScript, Vue.js y MySQL. He diseñado, desarrollado y desplegado yo solo **[Cuánto Es](https://micuantoes.com/)**, una aplicación en producción para comercios de Venezuela: backend, API REST, base de datos, frontend PWA y apps para Android y Windows.

Tengo experiencia previa en el sector público y como freelance, y uso la IA a diario para desarrollar y automatizar. Busco incorporarme a un equipo de desarrollo en remoto, híbrido o presencial.

### 🚀 Proyectos

#### [Cuánto Es](https://micuantoes.com/) · proyecto propio
> App de gestión para bodegas y pequeños comercios de Venezuela, hecha por mí de principio a fin. Está en producción y los primeros negocios ya la usan.

- Precios en dólares, bolívares y pesos colombianos con la tasa oficial del BCV actualizada cada día
- Ventas con cobros mixtos y vuelto, fiados, inventario, cierre de caja, proveedores y reportes de ganancia
- Funciona sin internet (PWA) y sincroniza las ventas sola al recuperar la conexión, sin duplicarlas
- Apps para Android y Windows, importación desde Excel, lector de código de barras e impresión de tickets por Bluetooth
- Automatizaciones con n8n y WhatsApp Cloud API: verificación de cuentas, recordatorios de cobro y resumen diario de ventas

`PHP` `CodeIgniter 4` `MariaDB` `Vue 3` `Vite` `PWA` `n8n` `WhatsApp Cloud API`

#### [Zamurove](https://zamurove.com/)
> Plataforma de ofertas para Venezuela con votos, comentarios, alertas y notificaciones push. Automaticé la búsqueda de ofertas con un agente de IA y GitHub Actions.

`TypeScript` `Next.js` `PostgreSQL (Prisma)` `NextAuth` `Tailwind CSS`

#### [DevLink](https://devlink.nygaccesorios.com/)
> Marketplace que conecta desarrolladores con clientes, con perfiles, gestión de proyectos, roles y búsqueda con filtros.

`PHP` `MySQL` `JavaScript` `Tailwind CSS`
